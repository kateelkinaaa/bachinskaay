# Тест Серафимы «Где именно вы себя потеряли»

Страница-тест для Telegram Mini App. Один файл, ничего собирать не надо.

## Что здесь лежит

- `index.html` — сам тест. Фото Серафимы вшито внутрь файла, отдельной картинки не нужно.

## Как включить GitHub Pages

1. Settings, раздел Pages.
2. Source: Deploy from a branch. Branch: main, папка `/ (root)`. Save.
3. Через одну до трех минут наверху появится адрес вида `https://логин.github.io/serafima-test/`.

Этот адрес вставляется в BotFather при создании мини-приложения (`/newapp`).

## Как обновить тест

Add file, Upload files, перетащить новый `index.html` поверх старого, Commit changes. Адрес не меняется, изменения появляются за минуту.

Если в телеграме видна старая версия, закройте мини-апп и откройте заново, либо добавьте к адресу `?v=2`.

## Настройки внутри файла

В начале тега `<script>` лежит блок настроек:

- `CHANNEL_LINK` — постоянная ссылка на закрытый канал, работает как запасной вариант
- `BOT_LINKS` — семь прямых ссылок BotHelp под типы результата: A, B, CP, CS, DP, DS, E. Пока строка пустая, кнопка ведет на `CHANNEL_LINK`
- `WEBHOOK_URL` — необязательно, адрес для сбора всех ответов в таблицу

## Типы результата

| Код | Результат |
|---|---|
| A | Вас нет в собственном списке |
| B | К себе вы строже, чем к кому-либо другому |
| CP | Отношения держите вы (в паре) |
| CS | Вы всегда были той, кто держит (без пары) |
| DP | Рядом человек, а вы все равно одна (в паре) |
| DS | Рядом чаще оказываются те, с кем нельзя сблизиться (без пары) |
| E | Ваш масштаб не совпадает с вашей жизнью |
